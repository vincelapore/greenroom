Next.js starter reserved for a project called Greenroom. Still the create-next-app template on the live URL.

**Live:** [greenroom-snowy.vercel.app](https://greenroom-snowy.vercel.app)

## Overview

Empty App Router scaffold. The npm package was incorrectly named `vellum`; it's now `greenroom`. I'll fill this README with real product detail once there's something to show.

## Tech stack

- Next.js (App Router), React, TypeScript, Tailwind CSS
- Hosted on Vercel

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

On Vercel with the default Next.js settings.
